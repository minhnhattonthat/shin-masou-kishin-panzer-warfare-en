# Skill gotchas

One line per gotcha: the reference file it belongs in, then the fact.

- references/platform-ps1.md: a font TIM whose CLUTs map only one bit of each 4bpp pixel to white (CLUT 0 = 0,FFFF,0,FFFF…) packs 4 glyph pages into one image; the glyph table's "page" picks the CLUT row. Edit only that bit when redrawing cells, or the other 3 pages break.
- references/pipeline.md §Marker: a sprite-per-glyph renderer can give each text window a fixed slot count (here 80) freed on close; English (about twice the glyphs per byte) overflowed it and left stray glyphs on later screens. Log each window's slot start/count before the width gate (`tools/lua/windows.lua` pattern).
- references/pipeline.md §Marker: a same-byte-length marker (each line → filler of the JP line's byte count) cannot overflow a full pool; pools here had zero slack even in Japanese, so `[id]` markers longer than the JP failed to insert.
- references/emulator-qa.md §Visual QA: typewriter glyphs fade in grey → white; judge a box on its settled frame, not mid-typing.

- references/platform-ps1.md: `iso9660.py` reads 2048-byte ISOs only; for a raw MODE2/2352 .bin, read the PVD at `16*2352+24` (this repo's `tools/disc_ls.py`).
- references/platform-ps1.md: script-text pools here are referenced by absolute RAM pointers inside fixed 16-byte commands; a RAM dump + `ramfind`-style chunk match found the load base in one step (`tools/ramfind.py`).
- SKILL.md / setup: context-mode trims Bash/Read output over ~4 KB even for `--help`; redirect help to a file and Read it with limit.
- references/graphics.md: no TIM scanner ships with the skill for PS1; this repo's `tools/tim.py` + `tools/montage.py` (find, decode, labelled contact sheets) did the survey.
- references/platform-ps1.md: ffmpeg's psxstr demuxer decodes a movie cut straight out of the raw .bin (2352-byte sectors from the file's LBA); split MOV.STR into movies where the STR frame number resets (`tools/str_movies.py`), then `-vf fps=1/3` frames + montage = FMV text survey in minutes, no jPSXdec.
- references/graphics.md: montage only byte-distinct TIMs (`montage.py --unique`) and skip the portrait size class: cut a 1500-TIM sweep from 33 sheets to 16.
- references/emulator-qa.md §Debug tool: the fastest PS1 warp was the main loop's mode-handler table (`jalr` on table[mode], mode word at `$gp`+x): forcing each mode once mapped game over, intermission, option, save screens and credits in 8 runs. Force it while a normal mode is starting (here the event), not from the title: the title's display setup drew garbage.
- references/emulator-qa.md §PCSX-Redux: a `.sstate` holds main RAM raw at file offset 0x27 (uncompressed), so Python can read RAM from states without the emulator (find it by matching an exe chunk).
- references/emulator-qa.md §Hooks: a Lua helper that re-queues a press whenever `L.route_done()` is true, called before a later `L.route_done()` check in the same frame, makes that check never pass; test the wait condition before tapping.
- references/platform-ps1.md: to find the font path, a read watch on the event text pool (`watch.lua`, `--debugger`) gave the string loop in one run; its glyph lookup was a binary search over a 6-byte row table (`first code, row, page`), not Krom.
- references/pipeline.md §Extract: don't require a NUL before a string start: here 31 event messages and several exe strings follow a pointer word directly (`... 1C 80` then text); taking every pointer target that decodes as text found them, the NUL-preceded scan missed them. Also a kana-run coverage scan (`sjis_scan.py`) over the whole event block caught the chapter-intro scroll pages, which no message command points at.
- references/emulator-qa.md §Free-space trap: `watch.lua` logs each PC once, so the boot-time CD DMA (one PC for every CdRead) hides every later load into the range; pass `FROM=<frame after boot>` (repo `trap.py --from`) or log DMA runs per load (`tools/lua/loads.lua`). A "follow-on load after the event block" in a RAM dump was the residue of an earlier, larger overlay in the same slot.
- references/platform-ps1.md: a full text pool can often grow by moving whole blocks to the end of their container file and rewriting the u16 sector list, when the loader takes [t[i], t[i+1]) and every disc file is found with CdSearchFile (no LBAs in the exe); check the loader's size cap (here `< 0x20` sectors) and keep any over-read past the file end (here 3 sectors into the next file) intact.
- references/translation.md §Review: `codex exec` can be quota-blocked for days (usage limit), and `-o` then leaves an empty report with exit 0; check the report size, fall back to reviewer subagents.
- assets/batches.py merge: on Windows `write_text` on script JSON hit a transient `OSError: [Errno 22] Invalid argument` (file held by a concurrent reader); re-running merge was clean (merge is idempotent).
- assets/batches.py: translators of parallel batches each invented their own wording for the game's stock defeat/retreat lines; seed those lines (same JP, many places) in the glossary or a wave-0 batch before wave 1.
